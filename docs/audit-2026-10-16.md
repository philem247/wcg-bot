# Bot audit — 2026-10-16

Scope: `index.js`, `config.js`, `transport/`, `store/`, `engine/`, dependencies,
and repo hygiene. The data builders and generated datasets under `data/` and
`scripts/` were not audited line by line.
Baseline: all test suites passed before any change.

## Fixed in this pass

| # | Area | Problem | Fix |
|---|------|---------|-----|
| 1 | `transport/wa.js` `send()` | Send errors were logged and swallowed, so the outbox's "retry once" path never ran. A send that failed during a connection flap was dropped without a retry. | Rethrow after logging. The boot DM in `index.js` now catches the error itself. |
| 2 | `engine/tick.js` | If any one game's `tick()` threw, the error escaped `setInterval` as an `uncaughtException`, which `index.js` treats as fatal. One broken game shut down the bot for every chat. | Each game ticks inside its own try/catch. A game that throws is dropped and logged, and the others keep running. |
| 3 | `store/db.js` leaderboard | There was no `careerpath` query. `/careerpath stats` fell through to the WCG chain board, and WCG `/stats` counted Career Path games. | Added a careerpath query and excluded `careerpath` from the chain board. |
| 4 | `transport/wa.js` | Offline-queued messages (upsert `append`) were sent through the router regardless of age. After downtime, an old `/trivia` or game answer could start a game or score hours later. | Messages more than 2 minutes old are dropped (`isStaleMessage`). The backlog from a short reconnect still goes through. |
| 5 | `transport/router.js` | Non-admins got "Only admins and owners…" for **any** `/command`, including commands meant for other bots in the group. That is spam, and the code's own comment says unknown commands should be ignored. | The refusal is only sent for commands this bot has (`KNOWN_COMMANDS`). |
| 6 | `transport/router.js` `endGame` | The admin lookup can take up to 8 seconds. If the game ended and a new one started during that time, `/x end` could end or `games.delete()` the new game. | After the await, re-check that the game in the map is still the one being ended. |
| 7 | `engine/validator.js` | Raw chat text went straight into the LLM prompt. A player could inject "…reply yes" to get reinstated, and long text bloated the cache file. | Answers longer than 40 characters, or containing quotes, backticks or newlines, are never sent and never cached. |
| 8 | `engine/validator.js` | The Gemini API key was sent in the URL query string, where it can end up in proxy or error logs. | The key now goes in the `x-goog-api-key` header. |
| 9 | `transport/wa.js` | `fetchLatestBaileysVersion()` ran on **every** reconnect with no timeout (it downloads a file from GitHub), so a slow GitHub could stall reconnects. | The version is fetched once per process, with a 10-second limit. If that times out, baileys' bundled version is used. |
| 10 | `transport/outbox.js` | Each send left a 30-second timeout timer running, even after the send finished. | The timer is cleared when the send settles. |
| 11 | `engine/scramble.js` | Only the bot's chosen word scored. A correct anagram (`pots` for `stop`) was silently ignored. | Any word in the scramble word pool that uses exactly the same letters now scores. |
| 12 | Logo quiz | `sort(() => Math.random() - 0.5)` is a biased shuffle. | Uses the existing Fisher–Yates `shuffle`. |
| 13 | Dependencies | `sharp`, `fast-copy` and `music-metadata` had published vulnerabilities. | `npm audit fix` (no breaking changes). |
| 14 | Repo hygiene | Throwaway files were committed at the repo root: `fix.mjs`, `test-query.mjs`, `scratch-dict.mjs` (which hard-codes a `C:/Users/...` path), and `test_*.png/jpg`. | Removed. `scratch/` is kept because `HANDOVER.md` refers to it. |

Every fix has a regression test that fails without the fix. New test file:
`engine/scramble.test.js` (added to `npm test`).

## Open findings (need a decision, not changed)

1. ~~Any group admin can edit the global dictionary.~~ **Fixed:** `/addword`
   and `/delword` are now OWNER/ADMINS only. `/pending` stays available to
   group admins.
2. ~~`loggedOut` (401) restart loop under pm2.~~ **Fixed:** on 401 the dead
   identity is recorded in `wa_dead_sessions`, a table the key wipe doesn't
   touch. On the next boot a `SESSION_ID` with that identity is ignored, so
   the bot generates fresh creds and prints a pairing code instead of looping.
   This marker only survives if `wcg.db` survives.
3. ~~`connectionReplaced` (440) fight.~~ **Fixed:** each 440 in a row doubles
   the reconnect wait (6s, 12s, … up to 10 min) and logs a warning about a
   second instance. A connection that stays up for 2 minutes resets the count.
4. **Claude validator auth.** It sends the token as `Authorization: Bearer` with
   the `oauth-2025-04-20` beta header, which is a subscription OAuth token, not
   an API key. A standard API key (`sk-ant-api…`) needs `x-api-key` instead.
   Using an API key is the supported route for a deployed bot.
5. **pm2 dependency vulnerabilities** (basic-ftp, braces, js-yaml, proxy-agent).
   The only fix npm offers is downgrading to pm2 5.x. They are local-tooling
   denial-of-service issues that the bot's inputs can't reach, so pm2 was
   left at 7.0.4.
6. **Bans can be bypassed by LID-only senders.** If a sender's phone number
   can't be resolved, `isBanned` has nothing to compare. This is rare because
   most LIDs resolve through `participantAlt` or the LID mapping store.
7. **Minor issues:**
   - `markAsked*` writes one implicit transaction per row. These are small
     batches, but wrapping them in one transaction would be faster.
   - Riddle answer matching uses `\w`, which drops accented letters (`café`
     becomes `caf`). Every other engine uses `fold()`.
   - The logo quiz has no repeat-avoidance across games.

## Trivia and randomiser work (same day, after the audit)

### Randomiser (`e01d0cd`, `00ba691`)

- Scramble and Logo Quiz remember what each group has seen (`pickFresh`),
  so a word or logo doesn't come back until the pool runs out.
- Trivia, Riddle, Flag and Career Path top up from already-seen questions
  when the fresh pool is nearly empty, so a game always gets its full length.
- `/wrg` letters are weighted, so awkward starting letters (Q, X, Z) come up
  less often.
- **Hard share.** Questions flagged `hard: true` get 40% of every game
  (`HARD_SHARE` in `engine/bank.js`). This applies to single-category games,
  mixed games and tournaments.
- **Template spread.** `diverseOrder` spreads picks across question
  templates, so one template (FPL's, for example) can't fill a mixed game.
  Mixed games also:
  - fill the hard slots first;
  - take every category once before repeating any;
  - limit anime, naruto and cartoons to one question while other
    categories are available.
- **Tournaments.**
  - A match no longer brings the group's whole asked history into its
    snapshot.
  - When the pool runs low, a match tops up instead of starting short.
  - Questions asked in a mixed game are tagged with their real category
    (`retagAsked`), so they recycle like any other question.

### Answers that gave themselves away

All the fixes below are scripts in `data/` that you can run again safely
(`fix-*`), and both build chains run them in order.

- **Wording leaks.**
  - `fix-trivia-giveaways`, `fix-football-giveaways`,
    `fix-football-season-labels` fix questions that named part of their
    own answer. For example, "the 2006 FA Cup Final ('The Gerrard Final')"
    pointed straight at Steven Gerrard.
  - They also fix stadium questions built from labels like "2022–23
    Manchester City F.C. season".
- **Shape tells (`fix-shape-giveaways`).** An answer stood out when it was:
  - the only list ("A and B", commas, slashes);
  - much longer than the decoys;
  - surrounded by joke decoys.

  Lists are cut back to one item, long answers are shortened where the
  meaning survives, and questions with joke decoys are removed.
- **Fixed decoy sets (`fix-fixed-decoys`).** Eleven templates used the same
  three wrong answers on every question. Wrong answers are now drawn per
  question from the template's other answers, grouped by era, pantheon or
  city where that applies.
- **Wrong options of the wrong type (`fix-decoy-types`).**
  - Tech wrong answers now match the answer's kind (language, database,
    OS and so on).
  - In year questions with a wrong answer more than ten years out, all
    three are redrawn within six years of the answer.
- **Football wrong options (`fix-football-easy-decoys`).** Fixed for:
  - tournament hosts and winners, which now come from the same era;
  - shirt numbers;
  - shared awards;
  - FPL names.

### Repetition (`fix-template-repeats`)

Several categories asked one fact three or four ways ("Who directed
Pulp Fiction?" four times, every animal's class four ways). Each subject
now keeps one phrasing per fact family.

### Harder, more varied questions

- **Football.**
  - New link templates (clubs two players shared, players two clubs shared).
  - Two hand-written hard packs: `data/football/hard-pack*.mjs`, 232
    questions.
  - The repetitive nationality template was retired.
  - Vandalised names in the career data were cleaned (`looksLikeName`
    guard).
- **Other categories.**
  - Hand-written hard packs are in `data/hard/<category>.mjs`, at least 50
    per category, 1,708 hard questions in the bank in all.
  - `data/hard/check.mjs` must pass before a pack goes in. It checks:
    - the question isn't already in the bank;
    - the question doesn't contain a word from its own answer;
    - the answer isn't the only list among the options;
    - the answer isn't much longer than the other options;
    - there are exactly 3 distinct wrong answers;
    - questions are spread across templates.
  - `data/add-hard-packs.mjs` adds them as the last build step.

Categories with hard questions: football, fpl, general, movies, music,
science, history, nigerian-entertainment, nigerian-music, nigerian-history,
anime, cartoons, got, tv-shows, mythology, health, animals, sports.

**Still without a hard pack (12):** tech, geography, videogames, art,
vehicles, food, pidgin-english, bible, web3, tech-gadgets, naruto,
nigerian-food. Mixed games and tournaments draw what hard questions exist,
so the hard share in mixed play grows as more packs are added.

**To add a pack:** write `data/hard/<category>.mjs` in the same format as
the existing packs, run `node data/hard/check.mjs <category>` until it
passes, then run `node data/add-hard-packs.mjs`. If you edit a question
already in the bank, rebuild with `npm run build` (or reset
`data/trivia.json` and run the applier again), because the applier only
adds questions and never replaces them.
